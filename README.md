# FF Name Styler — Free Fire Nickname Generator

A tiny, free stylish-name generator for Free Fire. Type a name, pick an ff name style, tap to copy — with a live 12-character counter so the name fits the game's rename box.

## Try it

Open `index.html` in any browser. No build step, no dependencies, no signup.

Or clone and serve it:

```bash
git clone https://github.com/d-roberts-dev/ff-name-styler.git
cd ff-name-styler
python3 -m http.server 8000
```

## Styles included

Small caps, bubble, wide, upside-down, and symbol frames (꧁ ꧂, ★彡, 乂, ♛, 『』, ツ) — the most popular free fire nickname styles.

## Why the 12-character counter?

Free Fire nicknames must be 3–12 characters, and every symbol counts as one. The counter turns red when a style is too long, so you never waste a rename card or diamonds.
